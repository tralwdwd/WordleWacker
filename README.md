# Wordle Wacker

Ever wanted to do Wordle but aren't bothered to try? Boy do I have the solution for you!

Meet WordleWacker, the easiest way to solve your daily Wordle without all that hard work!

## Usage

It's easy! Just go to the Wordle website, click play and the answer will be automatically typed in!

## Installation
Unzip source code in a known location on your computer, enable chrome extension developer mode, select "Load Unpacked" and choose the location the zip was extracted to.
